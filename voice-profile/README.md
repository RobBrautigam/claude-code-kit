# Voice profile

How your coding agent talks to you: verdict first, plain English, one idea per line, one question per message, always a next action under two minutes. Portable to Claude Code, Codex, Cursor, Grok, a local model, or anything that reads a rules file or takes a system prompt.

- [VOICE-PROFILE.md](./VOICE-PROFILE.md) - the standard and the reasoning behind it (one page each).
- [INSTALL.md](./INSTALL.md) - three steps, any agent.
- [EXAMPLE-before-and-after.md](./EXAMPLE-before-and-after.md) - the same answer in the default register and in this one.
- [drop-ins/](./drop-ins/) - the files you actually copy: a Claude Code rule, a `CLAUDE.md` snippet, an `AGENTS.md` snippet for Codex and friends, and a system-prompt block for everything else.

Start with `INSTALL.md`. Read `VOICE-PROFILE.md` when you want to know why a rule is there before you change it.
